# Jetson Sentinel — landing

Landing page for **Jetson Sentinel**, an offline, on-device autonomous
offensive-security appliance for authorized penetration testing and bug-bounty
engagements.

`index.html` is a self-contained static page — open it in a browser, or host it
anywhere that serves static files (e.g. GitHub Pages).

All addresses and domains shown are reserved documentation ranges
(`192.0.2.0/24`, `198.51.100.0/24`) and the fictional `.example` lab domain —
illustrative only.

**Design:** obsidian `#080A09` + ion green `#B7FF5A`; Inter Tight / IBM Plex Mono.
Responsive to phone width.
